## 3. 設計を無効化し得る仮定

1. **「ユーザーは Google ログインをブラウザ内で必要としない」** — これが誤りなら、製品の対象が大きく狭まる。
2. **「WebView2 のメモリは Edge より小さい」** — これが誤りなら、軽量性の主張が崩れる。
3. **「WebResourceRequested の往復は許容範囲」** — これが誤りなら、広告遮断の設計を変える必要がある。
4. **「ネイティブ UI を 1〜3 人で作れる」** — これが誤りなら、Tauri に戻るか、UI を簡素化する。
5. **「フィルタのライセンスは無改変配布で問題ない」** — 法務確認が必要。
6. **「Microsoft は WebView2 を今後も更新する」** — 現時点では事実だが、将来の保証ではない。

- Chromium fork の実際の保守コスト。
