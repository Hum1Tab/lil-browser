# ADR-0005: Cookie と履歴だけでなくサイトデータも保存する

状態: 採用
日付: 2026-10-23

## 文脈

当初要件は「永続データを Cookie と閲覧履歴に限定する」だった。しかし WebView2 は UDF に LocalStorage、IndexedDB、CacheStorage、Service Worker、HTTP キャッシュを自動保存する [S06]。禁止する API は無い。

## 決定

永続データを「Cookie、サイトデータ（LocalStorage/IndexedDB/CacheStorage）、履歴、設定」に限定する。パスワード、オートフィル、支払い情報、同期、テレメトリは保存しない。終了時削除オプションを提供する。

## 理由

1. サイトデータを消すと、ログイン、下書き、PWA、オフラインが壊れる。
2. Cookie だけ残してサイトデータを消すと、トークンを LocalStorage に置くサイトが壊れる。
3. 保存範囲を明示し、削除を提供し、送信しないことで、プライバシーを守りながら互換性を維持できる。

## 結果

- 保存量は「Cookie と履歴だけ」より増える。
- プライバシー表示に、保存するものを列挙する。
- 削除の物理的な完全性は保証しない。

## 代替案

- Cookie と履歴だけ: 互換性が大きく落ちる。不採用。
- すべて揮発: 毎回ログイン。日常利用に耐えない。オプションとして提供。
- サイト別の保存可否: 将来検討。UI が複雑になる。

## 再検討のトリガー

- WebView2 がサイトデータの保存を種別ごとに禁止する API を提供する。
- ユーザー調査で「毎回ログインでもよい」が多数になる。
