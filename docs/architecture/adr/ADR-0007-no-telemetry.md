# ADR-0007: テレメトリを実装しない

状態: 採用
日付: 2026-10-23

## 文脈

ブラウザの品質改善には、クラッシュ率、性能、サイト互換性のデータが有用である。一方で、テレメトリはプライバシーの侵害になり得る。

## 決定

テレメトリを実装しない。クラッシュログも自動送信しない。ユーザーが明示した場合だけ、ローカルのログをエクスポートする。

## 理由

1. 製品の価値提案の中心が「プライバシー」である。
2. テレメトリを送らないことで、通信の攻撃面と漏洩経路を減らせる。
3. 品質データは、任意のベータテスターから手動で集める。

## 結果

- クラッシュの統計が取れない。再現に時間がかかる。
- 性能の回帰を、ユーザー環境で検知できない。
- ベータ版では、明示的な同意を得たテスターだけからログを集める。

## 代替案

- opt-in のクラッシュ報告: 将来検討。既定はオフ。
- 匿名の性能メトリクス: 送信しない。ローカルに保存し、ユーザーが手動で共有する。

## 再検討のトリガー

- クラッシュの再現が困難で、品質に深刻な影響が出る。
- ユーザーから、明示的な opt-in の要望がある。
