# ADR-0003: Google 認証と DRM を対象外にする

状態: 採用（条件付き）
日付: 2026-10-23

## 文脈

当初の目的は「Chrome/Edge の代替として日常利用できるブラウザ」だった。しかし WebView2 には、ポリシーと実装に由来する欠落がある。

## 決定

Google アカウント認証と Widevine DRM を、製品の対象外とする。必要なら既定のブラウザで開く導線を出す。

## 理由

1. Google は埋め込み WebView からの OAuth を拒否する [S20][S21]。WebView2 も対象である [S08]。
2. Google の拒否理由は、ホストが通信を傍受しスクリプトを注入できることにある [S20]。広告遮断を行う本設計は、この threat model に該当する。
3. Widevine は WebView2 で未提供である [S33]（部分的証拠）。
4. UA 偽装や認証制限の回避は、要件として禁止されている。

## 結果

- Gmail、Google ドライブ、Google カレンダー、Netflix、Prime Video などは対象外。
- 対象ユーザーは「Google ログインをブラウザ内で必要としない人」に限定される。
- 製品説明と初回起動で、この制約を明示する。

## 代替案

- Chromium フォーク: 互換性は上がるが、更新追随と Widevine ライセンスの負担が大きい [S29]。
- UA 偽装: 禁止。安定せず、ポリシー違反。
- 外部ブラウザ委譲: API 連携では有効だが、Web サイトのログイン状態は移らない [S21]。

## 再検討のトリガー

- Google がポリシーを変え、埋め込み WebView を許可する。
- WebView2 が Widevine をサポートする。
- 対象ユーザーの 50% 超が Google ログインを必須とする。
