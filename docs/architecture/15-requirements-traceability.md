## 1. 状態の定義

| 状態 | 意味 |
|---|---|
| 完了 | 設計として扱い、判断を書いた |
| 条件付き | 設計はあるが、Gate 0 / PX の結果に依存する |
| 計画済み | 実装・計測の計画はあるが、未実施 |
| 対象外 | 制約または非目標により、意図的に扱わない |
| 未実施 | 依頼の範囲だが、まだ実施していない（実装、法務、実測など） |
