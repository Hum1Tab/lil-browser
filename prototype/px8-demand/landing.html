ネイティブ UI

Web UI の二重レンダラを持たない構成。UI はまだプロトタイプです。

できること（予定）

  • タブ、アドレスバー、履歴、設定、権限、ダウンロードの基本操作
  • 5〜20 タブを常時開く用途でのメモリ削減
  • 既定の追跡防止と、署名済みフィルタ更新
  • InPrivate。サイトデータは残さない（プロファイルファイルは残る）

できないこと（重要）

  • Chrome 拡張は使えません
  • Google の完全ログインは未検証です
  • Netflix などの DRM 再生は未検証です
  • 起動は Edge より遅いです（1 タブ 481 vs 293ms）
  • uBO と同じ遮断率は出ません

よくある質問

無料ですか？

需要検証中で、価格は未定です。有料化する場合は、事前に明示します。

Chrome の拡張は使えますか？

使えません。WebView2 はブラウザ拡張を提供しません。

Google にログインできますか？

識別子画面までは表示されますが、完全ログインは未検証です。保証しません。

Netflix は見られますか？

Widevine の EME は supported ですが、実再生は未検証です。保証しません。

起動は速いですか？

いいえ。暖機後で 1 タブ 481ms、5 タブ 456ms（Edge は 293ms / 310ms）。速さは売りにしません。

データは送られますか？

このモックは送りません。入力はブラウザの localStorage に保存されるだけです。本番ではプライバシーポリシーを用意します。
